# Awesome uBlacklist

A collection of curated blocklists for [uBlacklist](https://iorate.github.io/ublacklist/).  
These lists are split into **AI**, **non-AI**, and **category-specific** sets to help you filter search results without duplication.

---

## 📌 Lists Overview

- **awesome-full-ublacklist**  
  Includes **everything** (AI + non-AI categories).  
  👉 *Do not combine with any other list.*

- **awesome-ai-ublacklist**  
  Only AI-generated spam / AI-churned content.

- **awesome-nonai-ublacklist**  
  All non-AI sites (shopping, gaming, social, etc.) combined.  
  👉 *Do not install with category-specific lists.*

- **Category lists** (pick-and-choose subsets):  
  - `awesome-shopping-ublacklist`  
  - `awesome-gaming-ublacklist`  
  - `awesome-social-ublacklist`  
  - `awesome-entertainment-ublacklist`  
  - `awesome-webstore-ublacklist`  
  - *(more to come)*

---

## 🚀 How to Use

1. Install the [uBlacklist extension](https://iorate.github.io/ublacklist/).  
2. Open the extension options → **Subscription**. Select **Add a subscription**
3. Add the raw GitHub link for the list you want. Example:  
`https://raw.githubusercontent.com/
PhDuc/awesome-ublacklist/main/awesome-nonai-ublacklist.txt`
4. Click **Add** and the list will sync automatically.

---

## ⚠️ Avoiding Duplicates

- Use **only one** of these setups:
- `awesome-full-ublacklist`  
- `awesome-ai-ublacklist` + `awesome-nonai-ublacklist`  
- `awesome-ai-ublacklist` + one or more **category lists**  

👉 Do **not** install both `nonai` and the category lists (they overlap).  
👉 Do **not** install `full` with anything else (it already includes everything).
